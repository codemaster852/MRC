# MRC Website - دليل الاستخدام

## نظرة عامة
موقع ويب شامل لشركة MRC يعرض جميع مشاريعها ومنصاتها التعليمية والتقنية مع تصميم حديث ومتجاوب.

## الملفات المضمنة
- `index.html` - الملف الرئيسي للموقع
- `images/` - مجلد يحتوي على الشعارات والصور
  - `mrc_logo.jpg` - شعار MRC الرئيسي
  - `mrc_chess_tournaments_logo.png` - شعار بطولات الشطرنج
- `mrc_website.zip` - ملف مضغوط يحتوي على جميع ملفات الموقع

## كيفية الاستخدام

### 1. فتح الموقع محلياً
- قم بفك ضغط الملف `mrc_website.zip`
- افتح ملف `index.html` في أي متصفح ويب

### 2. رفع الموقع على الإنترنت
- ارفع جميع الملفات إلى خادم الويب الخاص بك
- تأكد من أن ملف `index.html` في المجلد الجذر
- تأكد من رفع مجلد `images` مع الملفات

### 3. تخصيص الموقع

#### تغيير المحتوى
- افتح ملف `index.html` في محرر النصوص
- ابحث عن النصوص التي تريد تغييرها وقم بتعديلها
- احفظ الملف وأعد تحميل الصفحة

#### إضافة مشاريع جديدة
ابحث عن قسم المشاريع في الكود:
```html
<div class="project-card">
    <div class="project-icon">XX</div>
    <h3>اسم المشروع</h3>
    <p>وصف المشروع</p>
</div>
```
انسخ هذا الكود وعدّل المحتوى حسب الحاجة.

#### تغيير الألوان
ابحث عن قسم CSS في بداية الملف وعدّل الألوان:
- `#667eea` - اللون الأساسي الأزرق
- `#764ba2` - اللون الثانوي البنفسجي
- `#ff6b6b` - لون الأزرار الحمراء
- `#28a745` - لون أزرار التحميل الخضراء

#### إضافة صور جديدة
- ضع الصور الجديدة في مجلد `images/`
- عدّل مسارات الصور في ملف `index.html`

### 4. الميزات المتضمنة
- تصميم متجاوب يعمل على جميع الأجهزة
- تأثيرات بصرية وحركات سلسة
- تنقل سلس بين الأقسام
- أزرار تحميل ملفات الموقع
- تصميم حديث ومهني

### 5. المتطلبات التقنية
- أي متصفح ويب حديث
- لا يتطلب قواعد بيانات أو خادم خاص
- يعمل كموقع ثابت (Static Website)

### 6. الدعم والتحديثات
لأي استفسارات أو تحديثات، يمكنك:
- تعديل الملفات مباشرة
- إضافة صفحات جديدة بنفس التصميم
- تخصيص الألوان والخطوط حسب الحاجة

## معلومات إضافية
- المؤسس: مصطفى هشام العطاوي
- التقنيات المستخدمة: HTML5, CSS3, JavaScript
- التصميم: متجاوب ومتوافق مع جميع الأجهزة
- اللغات المدعومة: الإنجليزية والعربية
